# Korean → Nepali Dictionary

A professional, responsive, offline Korean-to-Nepali dictionary generated from the supplied Excel dictionary.

## Features
- Korean and Nepali search
- Korean pronunciation with browser speech synthesis
- Similar words and opposites
- Favorites
- Dark mode
- Add Word (saved locally in the browser)
- Mobile-friendly responsive design
- No external libraries or internet required

## GitHub Pages
Upload `index.html` to the root of a GitHub repository and enable **Settings → Pages → Deploy from a branch → main → / (root)**.

## Sound
Pronunciation uses the device/browser speech-synthesis engine with `ko-KR`. For best results, install a Korean speech voice in Windows.
