# Korean–Nepali Dictionary

GitHub Pages-ready offline PWA using the vocabulary from `DICTIONARY(5).xlsx`.

## Run
Open `index.html` through a local web server (recommended) or deploy the folder to GitHub Pages.

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders in this project.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Open the generated Pages address.

The source workbook is not required at runtime; its cleaned vocabulary is stored in `data/words.json`.

## Included
Korean/Nepali search, favorites, local add-word storage, pronunciation via browser speech synthesis, dark mode, flashcards, quiz, export, responsive UI, and PWA offline caching.
